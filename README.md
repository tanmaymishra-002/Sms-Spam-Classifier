# 📩 SMS Spam Classifier
A machine learning web app that classifies SMS/email messages as **Spam** or **Not Spam** using TF-IDF and an SVC model.

### Live Demo
https://sms-spam-classifier-tanmay.streamlit.app/

### 📌 About
The project includes text preprocessing, TF-IDF vectorization, and an SVC classifier deployed as a Streamlit web application.
